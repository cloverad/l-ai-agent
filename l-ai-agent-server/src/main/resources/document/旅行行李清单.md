# 出国旅行行李清单（亚洲短途）

## 证件与文件
- 护照、签证页复印件、行程单、酒店预订单、保险单
- 身份证、少量现金（本币+目的地货币）、信用卡/储蓄卡
- 手机卡/eSIM、充电宝、充电线、转换插头（日本多为两孔A型）

## 衣物
- 按季节：薄外套、舒适步行鞋、速干内衣
- 雨具：折叠伞或轻便雨衣
- 若安排温泉：自备内衣（部分温泉馆不提供）

## 洗护与药品
- 牙刷牙膏、洗面奶、防晒霜、创可贴
- 常备药：肠胃药、感冒药、止痛药、防蚊液（夏秋）
- 隐形眼镜/眼镜备用

## 数码
- 手机、相机、移动电源（登机注意容量标注）
- 耳机、转换头、少量密封袋（收纳液体）

## 不建议托运
- 充电宝、充电宝相关锂电池、重要证件原件应随身携带
