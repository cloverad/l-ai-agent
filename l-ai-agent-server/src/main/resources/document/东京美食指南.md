# 东京美食与避坑

## 必吃方向
- 寿司：筑地外围市场或丰洲附近的立食寿司，午餐性价比更高
- 拉面：各区名店排队常见，可错峰或使用排队App
- 丼饭与定食：车站附近“大戸屋”一类连锁适合快速解决正餐
- 甜品：草莓三明治、布丁、抹茶甜品在季节限定时值得尝试

## 就餐礼仪
- 多数拉面店不提供纸巾以外的大量服务，结账看店内指示
- 大声喧哗、边走边吃在部分区域不礼貌
- 预约制高档店临时放鸽子可能被记入黑名单

## 预算参考
- 便利店一餐：800-1200 日元
- 普通拉面：1000-1500 日元
- 中档定食/丼饭：1200-2000 日元
- 寿司午餐：2000-5000 日元不等

## 过敏与饮食限制
- 提前用翻译软件准备“我对虾过敏”等常用句
- 素食选项在传统日料中相对有限，可优先印度餐厅或专门素食店
