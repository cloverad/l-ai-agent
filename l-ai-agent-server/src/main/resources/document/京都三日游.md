# 京都 3 日游经典路线

## Day1：东山文化线
- 上午：清水寺 → 二年坂/三年坂 → 八坂神社
- 下午：祇园町漫步，可体验抹茶甜品
- 晚上：先斗町或河原町用餐
- 提示：清水寺周边坡道多，穿舒适步行鞋；周末人流大，建议早到。

## Day2：岚山自然线
- 上午：岚山竹林小径 → 天龙寺
- 中午：岚山豆腐料理或码头附近简餐
- 下午：渡月桥散步，可选保津川游船（季节运营）
- 交通：京都站坐 JR 嵯峨野线到Saga-Arashiyama 站较方便。

## Day3：北野与金阁线
- 上午：金阁寺
- 下午：北野天满宫或龙安寺（视体力）
- 傍晚：返回京都站，采购伴手礼（伊藤轩、中村藤吉等）

## 预算参考（人均/天，不含大交通）
- 省钱：酒店 300-500 元 + 餐饮 150-250 元 + 交通门票 100-200 元
- 舒适：酒店 600-1000 元 + 餐饮 250-450 元 + 门票体验 200-350 元
