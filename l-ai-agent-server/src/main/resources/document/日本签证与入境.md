# 日本签证与入境常识

## 中国护照赴日旅游签证
- 个人旅游签证通常通过日本驻华使领馆指定的旅行社代办。
- 常见材料：护照、签证申请表、照片、行程表、酒店预订单、往返机票预订单、在职证明/学生证明、财力证明。
- 单次旅游签证停留期常见为 15 天或 30 天，以贴纸为准。
- 建议至少提前 2-4 周办理，旺季（樱花季、黄金周、年末）更早。

## 入境与海关
- 入境日本需填写入境卡（部分机场可电子化），准备好住宿地址与联系方式。
- 个人携带现金超过等值 100 万日元需申报。
- 肉类、水果、种子等动植物制品限制严格，违禁品可能被没收并罚款。
- 药品：常用处方药建议携带处方或说明书，部分感冒药成分在日本可能受限。

## 交通卡与支付
- 推荐购买 Suica / ICOCA / Pasmo 交通卡，地铁、巴士、便利店多可刷卡。
- 信用卡在大城市普及，但小型店、庙会摊位可能只收现金，建议保留部分日元现金。
